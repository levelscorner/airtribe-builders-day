# How to approach any problem tomorrow (Builders Day)

**Status:** locked for Sat 24 Oct 2026.
**Event:** Polaris / Brookefield, Bengaluru.
**Default demo:** Shopping AI, unless the morning booth cards clearly point at kirana, Learning, or Creators. If they do, pivot with the same orchestration pattern.

## Eight steps

1. **Name the outcome** the stranger leaves with (receipt / plan / lesson / audio file).
2. **Pick the track sentence** you can say in one breath.
3. **List 5–6 named components** mentors can point at (UI ≠ agent ≠ tools ≠ verify ≠ counter).
4. **Draw a lite DAG:** Supervisor + 2–3 nodes max; put Ranker only if you’re picking from a catalog.
5. **Freeze the allow-list / sample** by noon (SKUs, PDF page, or sample clip).
6. **One public Replit URL**; partner calls live or labeled **mock** — never fake success.
7. **Freeze build ~16:00** → chase ~20 outside users; second phone = same URL backup.
8. **Cut order:** voice DID → fancy mux → second host → multi-agent extras. Never cut verify honesty or the counter.
