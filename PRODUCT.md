# Product
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Indian creators making short educational, advertising, and narrated videos in Hindi, Hinglish, or English.
## Product Purpose
Describe an idea, answer only missing questions, refine a script in conversation, and review characters and scenes in a visual canvas before creating a video.
## Capabilities and Constraints
The Expo web application uses the existing Saturn REST/SSE service. Native mobile remains a separate surface. Local preview uses mock generation and sample credits; authentication, real payments, and live generation remain deferred. Reference attachments are stored in the current browser and are not read by the demo generator.
## Brand Commitments
The user explicitly chose a minimal ChatGPT/Gemini-like web experience, independent of the mobile UI. Spacious prompt-first home; plain submitted text; no workflow tabs; conversational approvals; a large canvas opening from the right. Explore new colours and typography.
## Product Principles
Keep creation conversational. Ask only for missing details. Review the script before generating visuals. Keep reviewable artifacts visible and preserve drafts on refresh.
## Accessibility & Inclusion
Keyboard-operable controls, readable Devanagari fallbacks, reduced-motion support, and responsive desktop/mobile web layouts.
