# Web conversation surface
Mode: Operate. Code-led implementation of the user's supplied screenshot and detailed journey.
Direction: quiet cool-white studio, graphite typography, desaturated blue interactions, DM Sans UI and Instrument Serif home headline. Deliberately independent from the native mobile theme.
First viewport: compact left rail, light wordmark, centered generous serif question, white prompt composer with attachment and send actions, three quiet example prompts. No setup form or workflow navigation.
Signature interaction: submitted prompt moves to the conversation's top and loses its composer chrome. After script approval, the right visual canvas expands to ~60% of the workspace while the conversation contracts. Reduced motion removes both transitions.
Quality bar: ChatGPT/Gemini clarity, keyboard operation, real REST/SSE approvals, script revision loop with visible cost and no silent advancement, recoverable drafts, honest sample media, mobile canvas with a clear return to conversation.

Configuration refinement: one persistent question block replaces its contents per answer; completed questions and answer messages do not accumulate in the visible conversation. Chosen options remain compact context inside the block. The API retains the underlying intake transcript for refresh recovery.
Generation boundary: live Higgsfield connector and setup are owned by the user's teammate. Do not implement or pull provider changes until the user says they are ready. Sample artifacts are only for testing UI; final acceptance of creation requires actual generated scripts and frames after that integration.

Completion: the active question box is replaced by one persisted configuration summary, before the script. No intermediate question or answer bubbles remain visible.
